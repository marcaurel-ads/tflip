# What the online maintenance procedures do while other connections use the
# table, on the remote server. sp_PackTableOnline leaves the table open (reads
# and writes, and what they write is in the packed table) until its final
# stage, which waits for the transactions on the table to end, signals
# `__OPFinalStage_<table>` and then takes the table; sp_ReindexOnline works
# the same and signals no event; sp_PackAllTablesOnline signals one event for
# each table it packs, a free table's folder's tables as well as a
# dictionary's. The Timeout option (seconds) bounds the wait for a
# transaction: 7176 for a pack, 7189 for a reindex, and the offline pack and
# reindex are refused (7008) meanwhile. A reader's open cursor does not hold
# an online pack back.
#
# The tables are not read between the online calls on them (see
# events_online_args.txt for why); the times are the original's, which a
# replay need not keep.
#
#     EV_SERVER_TYPE=2 ev.exe <ace32.dll> \\127.0.0.1:6262\data\<folder> events_online_procs.txt
#             > ../../../fixtures/events/events_online_procs.json
