# Who may change a user's password, and whether the old one is asked for:
# sp_ModifyUserProperty and AdsDDSetUserProperty (ADS_DD_USER_PASSWORD 1101,
# ADS_DD_CURRENT_USER_PASSWORD 1104 with the old password as the user name,
# ADS_DD_REQUIRE_OLD_PASSWORD 1105) by users who require the old password (r*,
# the default), users who do not (n*), another user's, a member of DB:Admin
# and a user holding ALTER on the user. Each attempt has a user of its own, who
# connects with the new password and then with the old one, so that the
# passwords the dictionary ends with say which attempt changed it. The
# dictionary, de/de.add, is kept in fixtures/sql/spddpwchange/:
#
#     run.sh <work> <ace32.dll> spddpwchange.txt > ../../../fixtures/sql/spddpwchange.json
#     cp <work>/data/de/* ../../../fixtures/sql/spddpwchange/
#
# Generated by spddpwchange.py (python3 spddpwchange.py > spddpwchange.txt): one
# user per attempt (r1.. require the old password, n1.. do not, a1.. are the
# targets of the administrator's, a member's and an ALTER holder's, whose
# runners are ad<N> and al<N>). The passwords are long enough that a wrong one
# is not taken by chance: the check of a one-character password is one byte.
