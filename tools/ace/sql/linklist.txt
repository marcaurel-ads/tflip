# A dictionary's links outside SQL: the tables of linked dictionaries in the
# table listings (AdsFindFirstTable62, AdsDDFindFirstObject of
# ADS_DD_TABLE_VIEW_OR_LINK_OBJECT), tables opened through a link by name,
# and the links a connection has active (AdsGetNumActiveLinks,
# AdsGetActiveLinkInfo). Run by sql.c on an empty data folder with copies of
# the props dictionary in props/ and of the dict one in dict/ (which the
# script changes: it adds links).
#
#     run.sh <work> <ace32.dll> linklist.txt > ../../../fixtures/sql/linklist.json
#
# The props dictionary has one link, selflink, to itself.

# Making a link that logs in makes it active, newest first. A global link is
# made without its password checked, but is then not active; a link of the
# connection's own with a wrong password is not made.

numlinks
linkinfo 1 200
ddlink dactive ..\dict\dict.add - - 3
ddlink dstatic ..\dict\dict.add alice secret 5
ddlink dlocal ..\dict\dict.add alice secret 0
ddlink dbadpw ..\dict\dict.add alice wrong 1
ddlink dlocalbad ..\dict\dict.add alice wrong 0
numlinks
