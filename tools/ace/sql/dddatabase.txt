# empty folder with a folder dc: the dictionaries it makes (the .add, .am and
# .ai files), where a relative path goes, the options, the refusals. The
# files it leaves are kept in fixtures/sql/dddatabase/:
#
#     run.sh <work> <ace32.dll> dddatabase.txt > ../../../fixtures/sql/dddatabase.json
#     cp <work>/data/dc/* ../../../fixtures/sql/dddatabase/
#
# Left out, as tflip does not write them (it refuses them with 2200): a
# PASSWORD that is not empty (the original enciphers it into the Database
# object), ENCRYPT TRUE (the whole file is enciphered), and ENCRYPTIONTYPE
# AES128 or AES256 with a DDPASSWORD (5214 without the OpenSSL libraries).
# Absolute paths fail under Wine with 7040 (File creation error), so are not
# recorded either.
