# What a cursor in a script sees of the changes made to its tables after OPEN
# where it reads a join of two tables (INNER JOIN, or a comma and a WHERE) of the
# equality of one column of each: it goes through the first table's records live
# (a record added meanwhile is read too), and for each finds those of the second
# that match its value now: through the second's index on its column as the table
# is then (a change of a key is seen), and with no index among the records that
# had that value at OPEN. The row of each pair is read as the records are, and
# kept if the condition still holds for them. The tables are made new for each
# case, so the records are in the order they were added. In an empty folder.
#
#     run.sh <work> <ace32.dll> cursormore3.txt > ../../../fixtures/sql/cursormore3.json
